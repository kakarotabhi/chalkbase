Classes and sections

The ladder this school runs, in the order it runs in, and the sections inside each class. These are facts about the school rather than about one year, so they carry over from session to session on their own. Nothing here is ever deleted — a class or section that stops running is switched off, stays in place, and can be brought back. It keeps its name while it is off, so bringing one back means switching that row on again rather than adding a second one with the same name.
