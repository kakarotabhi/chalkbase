Subjects

Every subject this school teaches. A flat catalogue, unlike the class ladder — English does not come before Mathematics — so the list reads alphabetically and nothing here can be reordered. Nothing is ever deleted: a subject that stops being taught is retired, stays in place, and can be brought back. It keeps its name and code while it is retired, so bringing one back means reinstating that row rather than adding a second one with the same name.
