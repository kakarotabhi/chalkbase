# See and acknowledge circulars

See the notices sent to your section, and record that a family has acknowledged one.

**Who can do this:** class teachers can see circulars and record an acknowledgement. Composing and
publishing a circular is the principal or vice principal's job.

## See a circular

1. Open **Communication → Circulars** from the menu.
2. Select a circular to see its full message, which classes and sections it was sent to, and how
   many families have acknowledged it so far, if it asked for one.

## Record an acknowledgement

If a family tells you — by phone, in writing, or in person — that they have seen a circular that
asks for acknowledgement, open it and select **Record acknowledgement** next to that student. This
is not the same as the family acknowledging it themselves in an app; there is no parent app to do
that yet, so this records that you were told, on their behalf.

## If you cannot see this screen at all

You need the "View circulars" permission, which your school's Class Teacher role holds by default.
If it is missing, ask whoever manages roles and access at your school to add it.
