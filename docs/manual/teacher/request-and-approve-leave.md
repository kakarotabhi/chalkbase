# Request and approve leave

Tell the register in advance that a student will be away, and decide whether that request should
show up as excused leave when someone comes to mark the day.

**Who can do this:** class teachers, for students on the section they teach, and the principal or
vice principal as a stand-in. There is no parent sign-in yet, so every request is filed by a
member of staff, usually on a call or a note from the family — not by the parent directly.

## File a request

1. Open **Attendance → Leave requests** from the menu, then select **New leave request**.
2. Choose the section, then the student.
3. Choose the first and last day the student will be away. A single day is a first and last day
   that are the same.
4. Say why — a sentence is enough. This is what whoever decides the request reads.
5. Select **Send request**.

A request can only start today or later. If a child was already away and nobody has said so yet,
this is not the screen for it — mark the day itself (present, absent, or whatever it was), then use
**Request a correction** on that mark if it should read as excused leave instead. Leave requests are
advance notice; a correction is what fixes a day that already happened.

## Decide a request

1. Open **Attendance → Leave requests**. Every request is listed, with a filter for pending,
   approved and rejected.
2. Open one to see the student, the dates, and the reason.
3. Select **Approve** or **Reject**. You may add a short note either way.

## What approving actually does

Approving a request does not, by itself, change anything on the attendance register. What it does
is this: when a class teacher opens the register for a section on a date an approved request
covers, any student not yet marked for that date is shown pre-set to **Excused leave**, with a note
that a request covers them. The teacher can still change it — if the child came in after all, mark
them present, the same as any other day. Saving the register is still the only thing that ever
writes an attendance mark.

If nobody opens the register for that date before it locks (a day and 24 hours later), the day
simply stays unmarked, the same as it would for any student on any day nobody marked at all.

## What is recorded

Every request, and its decision, goes into the audit log: who filed it, who decided it, and when.
The reason and any decision note are not shown in the audit log itself — only that they changed —
the same rule every other Confidential field in this product follows.

## If you cannot see this screen at all

You need the "View leave requests" permission to see the list, "Request leave" to file one, and
"Approve leave requests" to decide one. Your school's Class Teacher role holds all three by default.
If any is missing, ask whoever manages roles and access at your school to add it.
