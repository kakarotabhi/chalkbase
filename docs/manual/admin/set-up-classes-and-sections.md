# Set up classes and sections

Your school's ladder — Nursery through Class 12, or whatever your school actually runs — and the
sections inside each one. Students are admitted into a class and a section, so this comes before
anyone can be enrolled.

**Who can do this:** the principal and the vice principal. Teachers and admission counsellors can
see the ladder but not change it.

## Add the classes

1. Open **Academics → Classes** from the menu.
2. Select **Add a class**, type its name, and save. Use the name your school actually says — "Class
   5", "V" and "Grade 5" are all fine, as long as you are consistent.
3. New classes go on the end of the list. Put them in the right order with the **Move up** and
   **Move down** buttons.

Nothing is set up for you, on purpose. Schools genuinely differ — some start at Nursery, some at
Class 1, some finish at Class 10 — and a list you had to delete half of would be worse than an empty
one.

## Add the sections

Select a class, then **Add a section**. Sections are named per class, so every class can have its
own "A"; you are not naming them across the whole school.

## Retiring a class or a section

Nothing here is deleted — it is **switched off**. Select **Stop running** on the row. It stays
visible, marked as not running, and you can switch it back on at any time.

This is deliberate. Once a student has been enrolled into a class, deleting it would leave that
student's record pointing at something that no longer exists. Switching it off keeps the history
honest and still takes it out of the lists people pick from.

**A switched-off row keeps its name.** If you stop running "Class 5" and later want it again,
switch that row back on rather than adding a second "Class 5" — the second one will be refused,
because the name is still taken.

## If you made a typo

Rename it. Select the name, correct it, save. There is no need to remove anything.

## Academic sessions

**Academics → Sessions** is your school's list of academic years — 2025-26, 2026-27, and so on. Most
Indian schools run April to March, but you set the dates.

One session is the **current** one, and it is what the whole school sees by default. Changing it
affects everybody, so you are asked to confirm. Only one session can be current at a time: making a
new one current automatically ends the old one's turn.

Add a session before the year starts, so admissions for the coming year have somewhere to go.

## What is recorded

Every change here goes into the audit log: who added, renamed, reordered or switched something off,
and when. The log records which fields changed, never what they changed to.
