# Edit your school's profile

Your school's name, address, contact details and board affiliation. These appear on certificates,
receipts and reports, and go into UDISE+ returns — so it is worth getting them right once rather
than correcting them on every document later.

**Who can do this:** the principal and the vice principal. If your school splits the work
differently, ask whoever manages roles to add "Edit the school profile" to the role you want to have
it — it does not need a developer.

## Steps

1. Open **Settings → School profile** from the menu.
2. Fill in the three sections:
   - **Identity** — the school's name, its board, and your affiliation or registration number with
     that board.
   - **Location** — the address as it should appear on a certificate, including the PIN code.
   - **Contact** — the principal's name, and the phone, email and website parents and the board
     should use.
3. Select **Save changes**.

You will see "School profile saved". Everyone at the school sees the new details straight away —
there is nothing to publish or approve.

## The school code cannot be changed here

The code is shown but you cannot edit it. It is what everyone at your school types to sign in, and
it is written into every record the school has already created. Changing it would sign everybody out
and leave old records pointing at a school that no longer exists.

If the code is genuinely wrong, it has to be corrected centrally. Contact support rather than
working around it.

## When it goes wrong

**"This school's profile is not filled in yet."** Nothing is broken. No one has filled it in before,
so the form starts with the little that was entered when the school was set up. Complete it and
save.

**A field is highlighted in red.** The message under it says what is wrong — usually a PIN code that
is not six digits, or an email address missing its `@`. Fix that field and save again; nothing else
you typed is lost.

**"Could not load the school profile."** Usually the connection dropped. Select **Try again**. If it
keeps failing, someone else may be doing maintenance — wait a few minutes before retrying.

**You leave the page with unsaved changes.** You will be asked to confirm first. Choosing to stay
brings you back to the form with everything you typed still there.

## What is recorded

Every save is written to the school's audit log: who changed the profile, when, and which fields
they changed. The log records the *names* of the fields, never the old or new values. Anyone with
the Auditor role can read it.
