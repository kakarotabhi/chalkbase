# Set up subjects

Your school's list of subjects — English, Mathematics, Environmental Science, and whatever else you
teach. This is a flat list, not a ladder: subjects have no natural order the way classes do, so
there is nothing to move up or down here.

**Who can do this:** the principal and the vice principal. Class teachers, subject teachers and
admission counsellors can see the catalogue but not change it.

## Add a subject

1. Open **Academics → Subjects** from the menu.
2. Select **Add a subject**, type its name and a short code, and save. The code is your school's
   own shorthand for a mark sheet or a timetable cell — "MATH", "SST" — and it is not reshaped, so
   type it exactly as you want it to appear.
3. The list is always alphabetical by name.

Subjects are not yet linked to a class, a section or a timetable — that comes with the timetable
and marks features, which are not built yet. For now this screen is only the catalogue itself: what
this school teaches, in one place, so those later features have somewhere to point.

## Retiring a subject

Nothing here is deleted — it is **retired**. Select **Retire** on the row. It stays visible, marked
as retired, and you can bring it back at any time with **Reinstate**.

**A retired subject keeps its name and its code.** If you retire "Hindi" and later want to teach it
again, reinstate that row rather than adding a second "Hindi" — the second one will be refused,
because the name and the code are both still taken. If the screen tells you a name or a code is
already in use, check the retired rows first; that is usually where it went.

## If you made a typo

Select **Edit**, correct the name or the code, and save. There is no need to remove anything.

## What is recorded

Every change here goes into the audit log: who added, edited or retired a subject, and when. The
log records which fields changed, never what they changed to.
