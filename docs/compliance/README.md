# Compliance

Evidence and mappings for the obligations in
[docs/requirements/03-india-compliance-requirements.md](../requirements/03-india-compliance-requirements.md).

| Area | Reference | Status |
|---|---|---|
| UDISE+ reporting | https://udiseplus.gov.in/ | not started |
| APAAR ID handling | https://apaar.education.gov.in/ | not started |
| CBSE disclosure and affiliation records | https://www.cbse.gov.in/ | not started |
| RTE Act 2009 obligations | https://www.indiacode.nic.in/ | not started |
| DPDP Act 2023 — consent, retention, erasure, breach | https://www.meity.gov.in/ | not started |
| Child safety (NCPCR, NDMA) | https://ncpcr.gov.in/ | not started |

This folder holds the *evidence* — field mappings, export formats, retention schedules, consent
records and the decisions behind them — so an audit does not become an archaeology exercise.

None of this is legal advice. Validate workflows with the board, the state education department, a
school accountant and a legal advisor before launch.
